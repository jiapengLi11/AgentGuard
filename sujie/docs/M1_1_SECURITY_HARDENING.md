本记录是在已验收的 M1 合成任务闭环之上进行的代码变更；不将其解释为题目 5 的完整实现或真实 LLM 防御成绩。

## 已完成

- 网关在执行前检查合约和 Grant 到期时间，按任务在进程内原子扣减工具与网络调用预算。ASK 提议预留网络预算；审批提交继续检查合同、Grant、工具版本与动作绑定。
- 合约中的策略哈希改为实际 YAML 文件字节哈希；哈希不一致时拒绝执行。`data.transfer` 是新配置中的规范效果名，运行时仍将旧的 `external.data_transfer` 禁令作为禁止外发处理。
- 敏感资源由网关的可信资源清单指定，而非通过文件名后缀猜测。M1 默认清单保留合成 `secret.txt`；接入新任务前必须提供相应资源标签。
- Operations MCP Server 在 POSIX 平台使用目录文件描述符和 `O_NOFOLLOW` 打开文件，拒绝符号链接及多硬链接读取；写入使用临时文件和原子替换，避免现有硬链接目标被改写。Windows 开发环境做现有路径别名检查，但未声称具有 POSIX 的原子路径保证。
- MCP 读取内容形成经过 Schema 校验的 Artifact；网关记录读取、向 Agent 暴露、后续提议和实际影响的因果边。事件载荷和 Artifact 可选写入 SQLite，Agent 可访问的 `/v1/trace` 仍只返回不含正文的事件。Compose 的 SQLite 文件位于容器 tmpfs，容器删除后不保留。
- ASK 绑定使用实际参数内容哈希和来源快照哈希，不再使用空集合占位哈希。

## 验证

在 Windows Python 3.12 环境运行 `python dev.py check`：178 项通过，2 项跳过；一项因当前主机没有创建符号链接的权限，另一项仅适用于 POSIX。另在 WSL Ubuntu 22.04 用标准库探针调用 Operations 文件函数，确认预存符号链接、硬链接均被拒绝，正常写入成功。正式 POSIX pytest 已加入 `tests/test_operations_posix.py`，仍需在安装完整依赖的 Linux CI 或容器中运行；本次尚未重跑原 Ubuntu VM 容器验收。
