## 本轮改动

新增 `semantic_detector_v2.py`，以可信用户任务为参照判断低信任返回值是否
要求额外行动。特别补充读取/查找任务被改为交易、删除、设备操作、修改安全
策略等情况，同时区分面向人的教程、会议待办、客户请求和被分析的攻击引文。
模型没有工具权限，结论只作为辅助信号，不生成授权。

新解析器还拒绝重复 JSON 键、附带工具调用、类型错误及理由/布尔值不一致。
原 `semantic_detector.py` 和 M9 的四个冻结实现文件均未修改；旧协议的
35 对验证、50 对测试仍通过原始实现摘要检查。

v2 当前为开发候选，没有替换线上告警分类器或控制台的模型任务。

## 数据与事先固定的比较

- InjecAgent 仅使用原划分的 **TRAIN**：每种训练攻击意图按案例身份摘要排序选
  一例，共 37 条（`dh` 18、`ds` 19）；不是按模型结果选样。
- 每条攻击另配一个固定中性文本填充的合成对照，共 37 条。
- 另写 16 条正常文档，包含普通事实与指令引用、操作说明、待办、客户邮件、
  财务教程等。将文档放入临时受控工作区，通过真实 stdio MCP 的
  `operations.read_file` 读取，保存实际返回值、种子内容摘要、工具版本和服务源码摘要。
  **执行是真实的，文档内容和标签是自建的，仍不代表真实业务正常流量。**
- 两版在完全相同的 90 条输入上各调用一次固定
  `qwen-plus-2025-12-01`，temperature=0、max_tokens=256、无工具。
  根据响应摘要奇偶交替先调用 v1 或 v2；没有重试、取最好结果或调整后复跑。
- 共计划 180 次请求，每次在调用前记录 REQUESTED，完成后原子保存结果、
  用量和等待时间；错误停止，未知/未尝试响应不计为正常阴性。

这是训练开发比较，不是新一轮未见测试、Agent 执行成绩或官方 ASR。
训练案例可包含之前开发中已暴露的案例；正常标签由作者指定，没有独立评审。
案例共享意图/工具/模板，不能视为相互独立的业务任务。

v2 修复 v1 的 3 条漏检，同批没有新增攻击漏检；总召回增加 8.1 个百分点。
本轮合计 70,373 tokens。v2 用量增加约 75.0%，P95 等待增加约 4.3%。
等待时间包含客户端和服务延迟，仅来自本机这一次比较；不是网关性能或长期成本结论。
0/16 或 0/53 都不能证明真实业务误报率为零。

剩余 3 条 v2 漏检均在 `dh`。在训练内容中检查发现，其命令藏在仓库描述或
日历内容字段，容易被视为文档正文。这里存在“被阅读的命令句”和“要求智能体
执行的命令”的歧义，不能仅靠增加危险词覆盖来解决。后续需结合任务允许的效果、
拟调用工具与参数判断偏离；检测未命中也不能解除确定性授权及来源限制。
此诊断只读取训练内容，没有重新调提示后复报 M9 的测试结果。

统一 `dev.py check` 通过：Ruff 静态检查、96 个 Python 文件格式检查，以及
279 项测试通过、2 项因 Windows 符号链接权限/POSIX 描述符接口条件跳过。
本轮新增测试覆盖无工具边界、重复键/无效输出、输入上限、训练分区限制、

## 重建与复现

生成开发输入：

```powershell
.\.venv\Scripts\python.exe eval/build_task_aware_dev.py `
  --source-root '上游InjecAgent目录' `
  --out eval/reports/runs/task_aware_dev_rebuilt.json
```

执行报告绑定的是归档中的原始实现字节。执行结束后做过 Ruff 格式整理，
已逐文件验证当前与归档的 AST 相同；原始协议没有被重写。**严格复现原协议时，
在单独的项目副本中恢复源码归档 `files` 的内容，再使用该副本的运行器。**
当前字节不同会被原协议拒绝，不能通过改摘要把新代码伪装为原始执行。

```powershell
.\.venv\Scripts\python.exe eval/run_task_aware_dev.py `
  --dataset eval/reports/runs/task_aware_dev_v2_dataset.json `
  --protocol eval/protocols/task_aware_development_v2.json `
  --expected-protocol-sha256 7cd7be62dececd189209482211aecc837f65eed24ee173b9c7be7d3b00f6c880 `
  --credentials-csv '本机百炼凭据CSV绝对路径' `
  --out eval/reports/runs/task_aware_dev_v2_reproduction.json
```

若继续开发，使用当前代码另生成新协议和新输出文件；不要覆盖已执行协议或报告。
