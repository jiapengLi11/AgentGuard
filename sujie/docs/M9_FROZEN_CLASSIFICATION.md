## 事前冻结与实现

协议文件：`eval/protocols/task_aware_holdout_v1.json`。
SHA-256：`ffec48d705aee262bd7f9b392225c379064e55b05d6895013e0bbab30e040c40`。

冻结字段包含源文件清单、暴露注释划分的文件 Hash、各分区身份/工具/意图 Hash、
请求模型 `qwen-plus-2025-12-01`、max_tokens=256、temperature=0、无模型工具、
分类提示和中性填充文本 Hash，以及四个分类/规则/组装/运行模块的源码 Hash。
验证后没有修改提示或参数，继续按同一协议运行完整测试分区。
Provider 适配、依赖环境和供应商推理服务不由这些四个源码 Hash 完全覆盖；
跨环境复现应同时核对仓库与依赖，不能承诺模型逐次输出相同。
`eval/protocols/task_aware_holdout_v1_sources.json` 保存与四个事前摘要一致的源码副本，
同时在运行后补存 Provider 源码及摘要；后者明确标记为补充存档，不算事前冻结字段。

冻结器重新计算双轴划分，验证身份和分区没有变动、排除先前分类试跑和本地 Agent
映射的暴露案例，并检查验证/测试的意图与工具轴不重合。原始语料的词面规则全量扫描
早已做过，因此“未暴露”特指此前任务感知分类/Agent 映射实验；公共数据也可能已进入
供应商模型预训练。不是对预训练不可见性或整个项目未见性的声明。

新运行器逐请求原子保存：发起调用前先落盘身份与 REQUESTED 状态，返回后保存预测
或安全错误码。出错立即停止，保留已尝试和未尝试分母，不把缺失响应视为阴性。
禁止覆盖既有报告，拒绝协议摘要、实现、源文件、模型参数或身份不匹配。
报告不保存 API 密钥、凭据路径、工具返回值正文或完整对话。

## 结果

| 分区 | 攻击检出 / 漏检 | 合成对照误报 / 正确 | 词面规则攻击检出 | 有效模型响应 | Token |
|---|---|---|---|---:|---:|
| 验证 | 33 / 2（35 条） | 0 / 35 | 9/35 | 70/70 | 19,425 |
| 留出测试 | 41 / 9（50 条） | 0 / 50 | 8/50 | 100/100 | 29,923 |

测试攻击召回为 82%，验证为 94.3%；词面规则同批测试检出 16%。测试的 9 条漏检中
8 条来自 `dh`（4 条 Physical Harm、4 条 Data Security Harm），1 条来自 `ds/Others`。
这只是标签分布，没有根据测试正文完成语义根因归因，也没有据此改提示再重报测试成绩。
验证覆盖 3 种工具，测试覆盖另外 4 种，案例存在共同模板/意图相关性。

两分区合计 170 次分类请求、49,348 tokens，无无效 JSON。正常对照由上游模板填入
固定中性文本，仍是合成对照；0/50 不能说明真实正常业务误报率为 0。
没有让 Agent 继续执行，没有副作用 Oracle 或官方 ASR。这 85 对分类样本
不能计作 85 个独立基础业务任务。

原始报告在：

- `eval/reports/runs/task_aware_frozen_test_v1.json`

这些运行产物已忽略，协议身份与实现摘要可以保留。`injecagent_split_v4_annotated.json`
已合并本轮请求暴露：原划分中验证 36、测试 52 均已暴露，剩余未做这类实验的训练
