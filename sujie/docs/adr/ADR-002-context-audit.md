# ADR-002：F2模型上下文审计事件与契约包0.2

> **2026-10-15 交接更新：** 决策继续有效：契约包0.2、载荷1.0。当前主/子/Memory和引用分析已接入相关事件，历史分类/独立评测入口仍未全部统一。REQUEST_CHECKED/暴露登记都不等于供应商已收到或完整HTTP有效请求已绑定。旧0.1证据不重写升级。
> 完整现状、启动与证据限制见[交接手册](../PROJECT_HANDOFF.md)。

状态：按用户2026-10-14实施授权接受。来源：F2 W1/W6/W9。

新增Trace事件 `CONTEXT_REGISTERED`、`MODEL_REQUEST_CHECKED`、
`MODEL_RESPONSE_CHECKED`、`MODEL_EGRESS_BLOCKED`。它们分别表示候选上下文登记、
请求检查、回应检查和拒绝；检查记录不等于供应商已经收到或模型已成功处理。
原 `MODEL_EXPOSED` 是历史Host暴露集合登记，不能用于推断云端实际收到保护数据。

契约包升为0.2，各Schema的标识URI和LF摘要同步更新，共享枚举加入新事件，
载荷schema_version仍为1.0，已有字段/授权不变量及旧事件均保持。
HTTP session与导出标注包版本。旧0.1闭合枚举消费者需升级后读取新事件；
不绕过Schema或摘要校验来兼容未知事件。

历史M0/M1证据按0.1保留；F2测试按0.2执行。无变更时不能自动重生成摘要。
