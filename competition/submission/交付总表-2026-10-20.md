## 七、报告源码绑定变更流程

报告正文必须引用一个固定提交，而该提交里必须已经存在对应的验证记录，因此绑定更新需要两个提交：

```sh
# 1) 先生成并提交验证记录（清单由 git 对象重算，拒绝覆盖已有文件）
python3 competition/submission/tools/build_report_binding.py \
  --code-baseline <40-hex-sha> --metrics <metrics.json> \
  --out docs/validation/MAIN_SYNC_VALIDATION_<日期>.json
git commit -m "docs: record <baseline> as the report binding baseline"   # → 得到提交 A

# 2) 把 A 的完整 SHA 与记录的 sha256 写入 latex/runtime-version.json，
#    并在正文中引用 A 的前 7 位，然后自行校验
python3 competition/submission/tools/check_report_latex.py
```

`check_report_latex.py` 会核对：正文确实引用了被绑定提交、该提交里的记录哈希一致、清单内每份源码的 blob 哈希一致，以及当前工作区是否仍与报告基线相符。
